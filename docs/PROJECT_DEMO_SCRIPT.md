## 2. Natural Language Logging (0:45 - 1:45)
-   **Visual**: Show Dashboard with typing preview active.

-   **Action**: Submit the text, watch the details card render without disappearing.

## 3. Analytics & AI Coach (1:45 - 3:00)
-   **Visual**: Show weekly charts, click on the AI Coach tab.

-   **Action**: Highlight the admin console and exit securely.
