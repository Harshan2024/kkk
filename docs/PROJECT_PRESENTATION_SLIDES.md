# CarbonTracker AI — Product Presentation Slides

This presentation outline supports developer demos, portfolio pitches, and design walkthroughs.

---

## Slide 1: Title & Vision
-   **Header**: CarbonTracker AI — Empowering Sustainability through Intelligence
-   **Subtitle**: Natural Language Carbon Accounting for Everyone
-   **Key Visual**: Fluid glassmorphic UI showcasing weekly carbon footprint meters.

## Slide 2: The Core Problem
-   **Bulletpoints**:
    -   *Friction*: Traditional carbon footprint calculators require long, tedious forms (flights, weights, utility bills).
    -   *Complexity*: Most systems are built on batch data entries, preventing daily behavioral adjustments.
    -   *Ambiguity*: Users struggle to translate numerical footprints (e.g. "12 kg CO₂") into tangible real-world equivalents.

## Slide 3: The AI Solution
-   **Bulletpoints**:
    -   *Natural Language Tracking*: Log actions instantly using plain text.
    -   *Verified Calculations Engine*: Automates unit/item mappings with DEFRA/EPA standards.
    -   *Smartphone equivalents*: Translates footprints into relative comparisons (e.g. "charging 150 smartphones").
    -   *AI coach recommendations*: Instant chat-based insights helping reduce weekly footprints.

## Slide 4: Engineering & Scalability (Tech Stack)
-   **Bulletpoints**:
    -   *Frontend*: Next.js 14, TailwindCSS, Recharts.
    -   *Backend*: FastAPI (Async ASGI), SQLAlchemy, spaCy NLP.
    -   *DevOps*: Multi-stage Docker, Nginx, GitHub Actions, Neon Serverless PG.
